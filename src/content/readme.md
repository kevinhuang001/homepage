# 你好，世界 👋

> 欢迎来到我的个人主页工作区 —— **它长得像 VS Code，但它不是编辑器**，
> 只是我用来展示自己的一张“名片”。

我是**前端开发工程师**，喜欢把产品做成干净、可靠、有细节的样子。
这个页面的每一个文件都可以点开，就像在编辑器里浏览我的资料一样。

## 🚀 快速开始

```js
// 双击左侧文件树里的文件，即可像使用编辑器一样浏览我的主页
const me = {
  focus: 'Web 前端',
  stack: ['React', 'TypeScript', 'Vite'],
  values: ['细节', '效率', '真诚'],
  city: '杭州',
};

console.log(`我是 ${me.city} 的一名 ${me.focus} 工程师`);
```

## ⌨️ 几个快捷键

- `Ctrl + Shift + P` 打开命令面板
- `Ctrl + B` 显示 / 隐藏侧边栏
- `` Ctrl + ` `` 切换底部终端
- `Ctrl + F` 打开搜索
