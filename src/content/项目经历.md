# 项目经历

## 🛠 开源组件库 —— mini-ui（2024.09 – 至今）

一套轻量的 React 组件库，追求小而美。

- 从 0 搭建 Monorepo + Vite 组件开发环境
- 实现 Button / Modal / Toast 等 12 个基础组件
- 编写完整文档与 40+ 单元测试

```tsx
import { Button, Toast } from '@zhangsan/mini-ui';

function Demo() {
  return (
    <Button
      type="primary"
      onClick={() => Toast.success('你好，世界！')}
    >
      点我
    </Button>
  );
}
```
