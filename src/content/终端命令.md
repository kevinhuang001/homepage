# 终端命令规范（Terminal Commands Spec）

> 底部「终端」面板的命令全部由 **`src/data/terminal.js`** 的 `TERMINAL_COMMANDS` 数组决定。
> 想加 / 改命令，编辑那个文件即可；本页就是写给你的说明。

## 一个命令对象

| 字段 | 说明 |
| --- | --- |
| `name` | 命令名（小写、唯一），终端里输入它 |
| `desc` | `help` 列表里对这一命令的一句话说明 |
| `usage` | （可选）用法提示，例如 `open <文件名>`；不填则显示 `name` |
| `aliases` | （可选）别名数组，例如 `['cls']` |
| `run(arg, ctx)` | 命令主体：一个 **JS 函数**，返回命令输出 |

## run 的参数

- **`arg`** —— 第一个参数之后的内容（字符串）。如 `open 关于我.md` 里的 `"关于我.md"`。
- **`ctx`** —— 上下文对象：
  - `ctx.open(node)` —— 打开左侧文件树里的文件（传 `ALL_FILES` 中的节点）
  - `ctx.files` —— 全部文件节点数组
  - `ctx.profile` —— 站主信息（姓名 / 职业 / 城市等）

## run 的返回值

| 写法 | 效果 |
| --- | --- |
| `'一段文字'` | 一行普通文本 |
| `['多行', '文本']` | 多行（元素可以是字符串或 `{ text, dim }`） |
| `[{ text: 'a', dim: true }, 'b']` | 支持 `dim: true` 的灰色行 |
| `{ clear: true }` | 清屏 |
| `undefined` / `null` | 无输出 |

## 完整示例

```js
{
  name: 'greet',            // 终端里输入 greet
  desc: '跟我打招呼',       // help 里显示
  usage: 'greet <名字>',
  run(arg, ctx) {
    return `你好，${arg || '世界'}！`;
  },
}
```

## 带 JS 计算示例

```js
{
  name: 'sum',
  desc: '两数求和',
  usage: 'sum <a> <b>',
  run(arg) {
    const [a, b] = arg.split(/\s+/).map(Number);
    if ([a, b].some(Number.isNaN)) return '用法：sum <a> <b>';
    return `${a} + ${b} = ${a + b}`;
  },
}
```

## ⚠️ 说明

命令里的 JS 会在你的**浏览器当前页面**直接执行，只为演示，**没有沙箱**；整个终端也只是装饰性质，不含安全边界。
